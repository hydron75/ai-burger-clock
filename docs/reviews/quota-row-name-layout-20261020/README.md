# 한도 행 이름 잘림 — 합성 Windows 검증

2026-10-20 KST. 모든 이미지의 이름·사용량·시각은 smoke의 **합성 데이터**이며 실제 계정 화면이 아니다.

## 범위

- 공통 `QuotaLine.NameText`는 기존 정규화된 `QuotaWindow.Label`, `ValueText`는 기존 사용률·이전 값 표시·간략 리셋 문구다. `ReadingText`는 생략하지 않은 기존 `Text`에 행별 비교 설명을 한 번 결합한다. 기존 `Text`·`Label`·ID·`Detail`·`ComparisonText`는 유지한다. 메타데이터/헤딩/placeholder의 새 필드는 null이다.
- `DisplayFormatting.MiddleEllipsis`는 호스트의 실제 글꼴 측정 함수를 받아 균형 있게 양끝을 보존하고 가운데만 생략한다. Unicode 텍스트 요소를 경계로 사용해 이모지·결합문자를 자르지 않는다. 극소 폭에서는 양끝 대신 `…`만, 그조차 들어가지 않으면 빈 문자열을 반환한다. 표시 이름의 유일성 보장은 아니다.
- Windows는 오른쪽 값의 전체 폭을 먼저 확보하고 6 DIP 간격 뒤 남은 폭으로 이름만 줄인다. 접근성 이름은 `ReadingText` 전체, 설명은 중복 없이 비운다. Provider 전체 상세는 그대로다. 파서가 이미 줄인 원래 이름을 복원하지 않는다.
- **Mac 코드는 이 변경에서 수정하지 않았다.** Mac이 `MacStatusPanel` 행을 이름/값으로 나누고 같은 공통 함수와 `ReadingText`를 연결한 뒤 검증한다. 창/팝오버 높이·행 수·색·막대·조회·알림·캐시·버전·배포 EXE는 변경 대상이 아니다.

별도 `Shared.Tests`도 **254,543건·ExitCode 0**. 새 smoke +182는 96/120/144/192 DPI 및 스크롤바 유무 폭에서의 글꼴 실측·이름 생략·오른쪽 동일 픽셀·Unicode 검사 176건, 합성 렌더 2건, 창/행/막대·행별 접근성 연결 4건이다. DPI별 비트맵 검사는 실제 4개 모니터 관찰을 뜻하지 않는다. 실제 OS 스크린리더 낭독은 미검증이다.

전후 smoke는 고정 before/after 슬롯에서 실행했다. 트레이 기록 추가는 0건이다. 기준 빌드 최초 두 번은 NuGet 취약성 피드 접근/캐시 오류(NU1900)로 중단됐고, 작업 전용 HTTP 캐시의 강제 복원 후 위 최종 빌드·검사를 통과했다. 취약성 검사와 warnaserror는 끄지 않았다.

기존 20 PNG 중 **13개 SHA-256 동일**. 나머지 **7개는 보이는 한도 행의 글자 영역 안에서만 변경**, 영역 밖 변경 픽셀 0이다. 상태/Provider 상세/통계/기록 화면은 동일하고, **layout JSON 14/14 SHA-256 동일**이다. client **748×1138px = 374×569 DIP**, 한도 viewport **342×214 DIP**, 행 **19 DIP** 및 막대/행 수는 유지한다. 별도 긴 이름/Unicode PNG 2개는 후보에 새로 추가한 합성 예시이지 기준 빌드와 같은 이름의 전후 쌍은 아니다.

검증 원본 로그·PNG는 비공개 `artifacts/local-quota-row-name-layout-20261020/`에 보존한다. 여기에는 합성 PNG 3개와 픽셀 비교 요약만 선별했다. 기존 2.8.0 배포본은 교체 없이 재실행하고 SHA-256 불변·프로세스 응답을 확인했다. 실제 계정 화면의 육안 확인을 주장하지 않는다.

## Mac 전환·확인 요청

- `MacStatusPanel`의 한도 행을 오른쪽 값 우선으로 배치하고 이름만 공통 `MiddleEllipsis`로 줄인다. AppKit 실제 11pt 글꼴의 후보 문자열 전체 폭을 측정한다. 기존 전체 `Text`를 파싱해 분리하지 않는다.
- `SpokenRow`와 VoiceOver에 `ReadingText ?? Text`를 한 번 연결한다. 이미 비교 문장이 포함되므로 `ComparisonText`를 재결합하지 않는다. Provider 상세/헤딩/메타데이터는 그대로 둔다.
- 공통 **254,543건**, `Mac/build.sh` 경고/오류, native `--smoke-test`, 현 한도 막대 개수·행 수·팝오버 폭/높이·스크롤·VoiceOver를 확인한다. 긴 공통 접두사/다른 접미사, 긴 접미사/다른 접두사, 이모지/ZWJ/결합문자, 0/9.9/99.9/100%, 이전 값·리셋 경과/미제공, 화면/글꼴 배율·스크롤 폭을 합성 데이터로 검사한다.
- 전체 원래 이름 보존·캐시 형식·80/180자 제한·충돌 번호·알림 40자 축약은 별도 BACKLOG로 보류한다. 이번 PR에서 넓히지 않는다. **Mac 전환·검증 뒤 사용자 병합 대기**이며 배포는 하지 않는다.
