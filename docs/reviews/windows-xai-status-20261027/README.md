# xAI 상태 카드 전후 이미지 (합성 데이터)

실제 계정 값이나 실제 계정 화면은 포함하지 않습니다.
기준은 main `0ccd96fb1f388dbbc11be91a595344177f025350`, 변경 후 검사 코드는
`1787bb2d793badeaa464639159fd542371376df6`입니다.

## 상태 화면

| 변경 전 | 변경 후 |
|---|---|
| ![변경 전 세 상태 카드](before/full-throttle.png) | ![변경 후 xAI와 사용량 링크](after/full-throttle.png) |

기본 client 크기는 374×569→374×658 DIP입니다. 실제 200% DPI 캡처에서는
774×1209→774×1387 px입니다. 기존 세 카드 영역은 동일하고 네 번째 xAI 카드와
`사용량 보기` 링크를 추가했습니다. 하단 컨트롤은 89 DIP 내렸으며 Refresh 포커스 테두리 차이가 있습니다.
작은 작업 영역에서는 창 높이를 맞추고 본문을 스크롤합니다.

## 진행 사건 · 해결 없이 소실 · 명시적 해결

| 합성 진행 사건 | 해결 없이 소실 | 명시적 해결 |
|---|---|---|
| ![Grok Bot 일부 장애](after/xai-issue.png) | ![해결 미확인 CHECK](after/xai-missing-incident.png) | ![명시적 해결 뒤 정상](after/xai-resolved.png) |

확인된 진행 사건은 STOP, 해결 확인 없이 사라진 사건은 CHECK로 남습니다.
해결 표시를 수신하거나 첫 소실부터 24시간 뒤에도 정상 판독에서 미등장이면 정상으로 돌아갑니다.
24시간 만료는 공식 해결 확인 알림으로 보내지 않습니다.

## 소실 후 24시간 경과 (추가 합성 검사)

![24시간 만료 후 xAI 정상 표시](after/xai-expired.png)

검사 소스 `7312c1febe6fa3881d25dcf0c8001d0e4ebdd5bc`에서 첫 소실 시각을 고정해 24시간 정각의
공통 결과를 native 상태 창에 표시했습니다. 상세 Tooltip에
`해결 표시 없이 피드에서 사라짐(24시간 경과로 해제)`가 들어가는 것도 검사했습니다.
이번 보완 전의 기존 PNG 25개와 layout JSON은 모두 동일하고, 위 이미지 하나만 추가했습니다.
창 크기·카드 크기·행 수는 바꾸지 않았습니다.
